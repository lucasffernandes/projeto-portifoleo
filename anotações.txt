* SVG -> imagem vetorizada, pode ser usada como favicon.

* SVG utiliza xml para gerar imagens (xml é equivalente ao html só que para outras finalidades)

* Se modificar a extenção do SVG -> xml, o código da imagem é aberto para ser feito alterações desejadas.

pode ser modificado no código xml a cor de um elementos em imagem de duas formas:

  1- modificando a cor "exadecimal" da propriedade 'fill' que geralmente fica no final do código xml da imagem svg.

  2- adicionando um <style> dentro da configuração xml da imagem, e dentro do style criando um seletor com o nome:
  path{
  }

     - e dentro dessa path pode ser configurado elementos como: 
       * fill:black  - configura a cor de fundo da imagem
       * stroke: white -> configura a borda com a cor branca
       *stroke:width: 3px -> cria uma borda de 3 px;

* Depois de salvado as alterações, basta somente mudar novamente a image como svg, e estará a imagem alterada.

* transition: background-color 0.5s, color 0.5s
   - Nesse caso, o plano de fundo é modificado com transition, e o primeiro valor numérico é o temmpo que essa transição vai demorar

   - o segundo elemento a ser modificado é "color" e também recebe um valor que define o tempo que essa alterção vai demorar.

* fontawesome -> site de icones para projetos.

  - link de instalação de icones no código:

  <script src="https://kit.fontawesome.com/ec40fa2d48.js" crossorigin="anonymous"></script>

  - Esse link é colado no header (HTML) do projeto.

  - apos instalar esse código no cabeçalho, basta pesquisar o ícone no site e colar a tag(i) do icone desejado no local desejado projeto.

  * Para configuração de imagens, existe a opção 'aspect-ratio' que pode receber valores de dimencionamento de imagem, deixando ela no aspecto (tamanho desejado).
      - Exemplo de valor: 1/1 ou 9/16

  * Object-fit: concerta a imagem nesse configuração acima no tamanho delimitado.

  * outline funciona exatamente como uma borda comum, ela é uma borda externa a "border".
